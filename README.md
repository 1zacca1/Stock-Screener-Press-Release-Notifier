# Stock Screener

Investment research platform with four modules:

- **Deep Value** — small US companies trading near net cash with single-digit P/E
- **Value Screener** — EV/EBIT < 10×, 3-yr Rev CAGR ≥ 30%, 3-yr ROIC ≥ 30%, 3-yr ROE ≥ 30%
- **Spinoffs 2026** — live dashboard sourced from The Zen of Investing
- **News & Filings** — SEC EDGAR feed for tender offers, liquidations, going-private

Built with vanilla JS + Vercel serverless functions. Requires `FMP_API_KEY` env var.
